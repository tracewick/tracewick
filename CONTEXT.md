# Glossary

## Releases

- **Package contents** — the files distributed as a particular version of a Composer library.
- **Release artifact** — a downloadable output associated with a published release.
- **Contents manifest** — a versioned inventory of a package's file paths and content hashes.
- **Package SBOM** — an inventory of the software and files contained in a distributed package.
- **Application SBOM** — an inventory of the resolved software dependencies in an application.
